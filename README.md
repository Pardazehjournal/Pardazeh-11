# Pardazeh — Issue 11

Web version of the 11th issue of **Pardazeh**, the student magazine of the Computer Engineering Faculty, Shahrood University of Technology.

**Theme:** Opportunities, Challenges, and the Future Built with Zeros and Ones.

## About

This issue explores how Artificial Intelligence is entering different areas of life, industry, and science — from education and medicine to art, law, and the future of work.

## Features

- 15 in-depth articles on AI in various domains
- Interactive algorithm escape room
- AI Prompt Lab with ready-to-use prompts
- Full PDF version available for download

## Tech Stack

- React + Vite
- Lucide Icons
- Vazirmatn & JetBrains Mono fonts
