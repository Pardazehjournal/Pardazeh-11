2. SOURCE FIDELITY — ABSOLUTE RULE
Use ONLY the information contained in the provided text.
Never:
•	Invent information
•	Add outside facts
•	Add personal opinions
•	Create unsupported interpretations
•	Change the author's meaning
•	Fabricate statistics
•	Fabricate quotations
•	Invent examples
•	Invent conclusions
•	Present assumptions as facts
If an insight is an interpretation rather than an explicit statement, clearly label it as an inference and ensure that the inference is strongly supported by the text.
If the text does not contain enough evidence for an inference, do not make it.

Analyze the complete source before extracting insights.
Do not disproportionately focus on:

•	The conclusion

4. INFORMATION PRIORITIZATION
Classify extracted information into four levels:
🔴 CRITICAL
Information that is essential for understanding the central message or conclusions.
🟠 HIGH VALUE
Important information that significantly improves understanding or decision-making.
🟡 USEFUL
Relevant information that provides additional context or practical value.
🟢 OPTIONAL
Interesting but non-essential information.
Prioritize CRITICAL and HIGH VALUE insights.
Avoid filling the output with low-value details.

5. GOLDEN INSIGHTS
Identify the statements or ideas that provide unusually high value.
A Golden Insight should ideally have one or more of these characteristics:
•	Changes how the reader understands the subject
•	Reveals an important relationship
•	Explains why something happens
•	Identifies a critical cause or consequence
•	Provides a highly useful practical lesson
•	Challenges a common assumption explicitly discussed in the source
•	Connects multiple ideas in the source
•	Contains an important strategic implication
•	Prevents a significant mistake
•	Provides a useful decision-making principle
Do NOT call something "golden" merely because it is interesting.

INFERENCE
